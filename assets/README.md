# Assets

Put your images, illustrations, and other website files in this folder. Reference them from `index.html` with paths like `assets/my-photo.jpg`.

The Resume button links to `Alice_Liang_Resume.pdf` in this folder. To update your resume, replace that PDF with the newer version and keep the exact same filename and location. If you rename it, update the button's `href` in `index.html` to match. Upload the PDF along with the site when publishing so visitors can open it.
