# Assets

Put photos and menu artwork in this folder, and place decorative lettering and star artwork in `decorations/`. Reference them from `index.html` with paths like `assets/my-photo.jpg` or `assets/decorations/my-decoration.png`.

The Resume button links to `Alice_Liang_Resume.pdf` in this folder. To update your resume, replace that PDF with the newer version and keep the exact same filename and location. If you rename it, update the button's `href` in `index.html` to match. Upload the PDF along with the site when publishing so visitors can open it.

To customize the cute messages shown by the floating stars, edit the `window.starMessages` list in the site's root `star-messages.js` file. Keep each message in quotation marks and separate messages with commas.
